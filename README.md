## 👨‍💻 Sobre mim

Trabalho na **TOTVS** como Analista de Serviços no Suporte Prime, dando suporte especializado no ecossistema Protheus (Reforma Tributária, Smart View e módulos de Faturamento, Estoque/Custos, Compras e PCP).

No dia a dia mexo bastante com **ADVPL e TL++ (TLPP)**, banco de dados e administração de sistemas corporativos. No universo PHP, **Laravel** é o framework que mais domino e uso como referência em back-end.

Uso o GitHub como laboratório pessoal — projetos de estudo, automações e experimentos que não cabem no trabalho.
